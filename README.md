# Dr Assif Med Spa

Luxury aesthetic medicine website built with Next.js, Tailwind CSS, and Framer Motion.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Pages

- **Home** — Hero, featured services, before/after, testimonials, Instagram, contact strip
- **About** — Dr Assif introduction, mission, clinic environment
- **Services** — Injectables, skin, laser, wellness (with pricing placeholders)
- **Gallery** — Filterable gallery + before/after comparisons
- **Reviews** — Google-style review cards
- **Contact** — Phone, address, Instagram, WhatsApp, Google Maps (no forms)

## Tech

- Next.js 16 (App Router)
- Tailwind CSS v4
- Framer Motion
- TypeScript

## Notes

- No booking, scheduling, or contact forms
- Images from Unsplash (replace with real clinic photos in production)
- Update Google Maps embed URL with exact coordinates if needed
